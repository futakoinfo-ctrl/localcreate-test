# 🐍 貪吃蛇 Snake

單檔 HTML5 Canvas 貪吃蛇小遊戲，無需安裝、無外部依賴。

## 快速開始

1. 用瀏覽器直接開啟 `index.html`（電腦雙擊即可；手機可經 GitHub Pages 或傳檔開啟）
2. 電腦用方向鍵 / WASD，手機用滑動或螢幕方向鍵控制蛇移動
3. 吃紅色食物得分，避免撞牆與撞到自己

## 操作方式

| 裝置 | 操作 | 功能 |
|---|---|---|
| 電腦 | ↑ ↓ ← → / WASD | 上下左右移動 |
| 電腦 | 空白鍵 | 暫停 / 繼續 |
| 手機 | 在畫面任意處滑動 | 依滑動方向轉向（可連續滑動） |
| 手機 | 螢幕方向按鈕 ▲◀▼▶ | 上下左右移動 |
| 通用 | 「暫停」按鈕 | 暫停 / 繼續 |

## 手機支援

- 響應式棋盤：依螢幕寬高自動縮放，支援直向與橫向
- 觸控滑動 + 螢幕方向鍵（僅觸控裝置顯示）
- 禁止頁面捲動、雙擊縮放與下拉重新整理，避免操作時畫面亂跳
- 死亡時震動回饋（支援 Vibration API 的裝置）
- 切到背景或鎖定螢幕時自動暫停

## 遊戲規則

- 每吃一個食物 **+10 分**，蛇身增長一格
- 每吃一個食物，速度加快（間隔 -4ms，最快 70ms）
- 撞牆或撞到自身即遊戲結束
- 無法直接反向移動（避免瞬間自殺）
- 最高分以 `localStorage` 保存於瀏覽器，重新整理後仍保留

## 遊戲參數

位於 `index.html` 的 `<script>` 區塊，可自行調整：

| 參數 | 預設值 | 說明 |
|---|---|---|
| `GRID` | 20 | 每格像素大小 |
| `canvas` 寬高 | 400 × 400 | 20 × 20 格棋盤 |
| `speedMs` 初始值 | 140 | 初始移動間隔（毫秒） |
| 最快速度下限 | 70 | 加速上限（毫秒） |
| 每次得分 | 10 | 每個食物的分數 |

## 技術重點

- 純原生 JavaScript + Canvas 2D，無框架
- `setInterval` 驅動遊戲迴圈，吃食物時重設計時器以變速
- 以 `nextDirection` 暫存輸入，避免同一 tick 內連按兩鍵造成反向自撞
- 食物生成時排除蛇身佔用格，避免與蛇重疊
- 主題色以 CSS 變數定義於 `:root`，易於換膚

## 已知限制 / 可擴充方向

- 蛇填滿整個棋盤時（勝利條件）尚未處理
- 可擴充：難度選擇、穿牆模式、音效、障礙物
